# 📊 Sales Insights Dashboard

## 📌 Project Overview

This project is based on the **Codebasics Sales Insights** case study. It demonstrates how SQL and Power BI can be used to analyze sales data and build an interactive business dashboard. I implemented the project to strengthen my skills in SQL, Power BI, DAX, and business data visualization.

---

## 🛠️ Tools & Technologies

- SQL (MySQL)
- Power BI
- DAX

## 📊 Dashboard Features

- Revenue Trend Analysis
- Revenue by Market
- Revenue by Zone

- Executive KPI Cards

---

## 🔍 Key Business Insights

- Delhi NCR generated the highest revenue among all markets.
- A small number of customers contributed a significant share of total revenue.
- Revenue trends showed noticeable fluctuations over time.
- A few products generated the majority of sales.
- Sales performance varied across different geographical markets.
